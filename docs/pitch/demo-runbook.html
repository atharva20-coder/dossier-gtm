Four Runs to Rehearse

One happy path and three edge cases, with the exact input, what the screen does, and what to say while it runs. Every output below was captured from a real run.

Run them in this order. Confidence first, judgment second, honesty third, resilience last — each one answers the question the previous one raises.

  1. Happy path — a lead already researched, open before you start talking
  2. Two people share a name → it stops and asks
  3. Nothing real to say → it refuses to invent
  4. Every optional key is wrong → it still finishes

Two people share a name

edge case · run live
Input · type exactly this, leave company blank

Name: Michael Chen Company: (leave empty) Role: (leave empty)

Say, before running

“The most expensive mistake this process can make isn't a bad sentence — it's researching the wrong person and emailing a real one about them. So here's a name deliberately given with no company.”

What it actually returns 
status: needs_disambiguation
identity: 4 plausible matches — waiting for confirmation

  Adventist Healthcare  · Interventional Cardiologist
  Akin Gump             · Associate, Disputes & Investigations
  (no company)          · Actor
  (no company)          · Director of Operations
Say, pointing at the four

“It found four real people and stopped. It has not spent a research budget, and it has not guessed. The run parks here until someone picks — and picking costs one cheap pass, not a fresh start.”

If they push

“Why not just take the highest-confidence one?” — Because the cost is asymmetric. A wrong pick produces a fluent, confident, completely wrong email to a real person. Stopping costs four seconds.

Nothing real to say

edge case · run live
Input · a real-sounding person with no public footprint

Name: Harshad Vaidya Company: Kelphi Systems Role: Operations Lead

Say, before running

“Every tool in this space will write you a personalised email about anyone. That's the problem — the model will happily invent a funding round. Watch what this does when there's genuinely nothing.”

What it actually returns 
research  44 sources — 21 person-level, 23 company-level

          — the source never ties them to Kelphi Systems
judge     no candidate cleared the eligibility gates
draft     No specific public signal was found — this is a deliberately
          generic draft, labelled as such

status: no_signal_found
Say — this is the strongest moment in the demo

“It read forty-four sources, found fifteen facts about a different Harshad Vaidya, and threw every one of them away because nothing tied that person to this company.”

“Then it wrote a generic message and labelled it generic. It would rather hand back an honest blank than a convincing lie. That's the whole design in one screen.”

Every optional key is wrong

Say

“It completed. The address is calculated from the company's naming convention instead of looked up, and it says so — on screen, and in the CSV a sequencer would import.”

“Three keys failed and the run didn't. The only thing that changed is the reason it gives you.”

Restart afterwards

Kill that server and start a normal one before anything else, or your remaining demos will all run degraded and you'll be explaining it twice.

Held in reserve

Don't run these unless asked — four is already a lot for one call.

A colleague's fact, dropped. On a normal run the extract line reads “1 fact about a different person at the company discarded”. It fires on its own; point at it if you see it rather than staging it.

Only stale facts exist. The run picks the best of what remains, up to two years back, and says plainly: “nothing recent cleared the bar… read it before sending.”

An address that would bounce. A derived address verified as invalid is cleared rather than shipped, with the reason “looks like a typo for …”.

Two things to check an hour before

Run each of these once. Live search results move; the four candidates for Michael Chen may not be the same four next week. The behaviour will hold — the specific names may not, so don't quote them from memory.

Have the happy path already open in a tab. Never let an interviewer watch a loading spinner in the first thirty seconds.

Every edge case here is something that broke first, then got a gate. That is the honest answer to “how did you choose these” — they chose themselves.
