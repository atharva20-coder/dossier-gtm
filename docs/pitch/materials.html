Dossier — pitch materials

Eight documents. Each one does a different job, and they're meant to be read in a particular order.

If you only have an hour before the interview:
  1. Read What to Say at Zamp — the actual pitch, start to finish.
  2. Skim How Dossier Works — the five-word glossary at the top does most of the work.
  3. Run the four demos in Four Runs to Rehearse, in order.
  4. Read the first two sections of Questions About Your Thinking, then jump to the hardest ones.
